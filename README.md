# Barber App · Descargas

Aplicación para reservar citas y tomar turno en la fila de la barbería.

## 📲 Descargar para Android

**[⬇️ Descargar Barber App (APK)](https://github.com/Afandres/BarberApp-releases/releases/latest/download/barberapp.apk)**

1. Toca el enlace de arriba y espera a que termine la descarga.
2. Abre el archivo `barberapp.apk`.
3. Si el celular lo pide, permite **instalar apps de esta fuente**.
4. Toca **Instalar** y abre la app.

## 🍎 iPhone

Abre **https://afandres-barberapp.expo.app/descargar** en Safari y sigue las instrucciones para agregarla a tu pantalla de inicio.

Este repositorio solo contiene los archivos de instalación. Cada versión nueva se publica en [Releases](https://github.com/Afandres/BarberApp-releases/releases).
